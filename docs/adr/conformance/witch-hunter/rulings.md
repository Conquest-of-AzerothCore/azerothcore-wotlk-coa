# Witch Hunter conformance rulings

The owner rulings and method decisions for the Witch Hunter (class 15). The rules that bind every class, the Templar
precedents and the meaning of the columns ("Who decided", "Recorded in") are on the common page,
[class-conformance-rulings.md](../../../coa/class-conformance-rulings.md). "Recorded in" names the Witch Hunter ADR
in this folder that states or applies the decision; "No ADR found" means this page is its record.

Each is binding for the Witch Hunter only. The owner answered the Witch Hunter decision page on 2026-11-15; the mentor
relayed the answers. An owner ruling is the expected behaviour and counts as the independent source of G-37
(criterion 3). A ruling that asks for a server change is not yet applied: it still needs a fix note with the cause
read, the narrowest change, a regression and an ADR.
