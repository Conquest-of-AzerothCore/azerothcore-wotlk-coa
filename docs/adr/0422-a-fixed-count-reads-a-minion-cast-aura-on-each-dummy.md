# 0422. A fixed count reads a minion-cast aura on each dummy

- Status: accepted
- Date: 2026-11-13

## Context

Command: Bonefreeze 504489's freeze 504845 is cast by the Skeletal Mage, not by the player, on every enemy within 8 yd
of the Command's target. `fixed_count` with `metric: "aura"` read each dummy's aura filtered to the player as caster,
so a minion-cast aura always read 0.

## Decision

With a `caster_entry`, an `aura` read of `fixed_count` names no caster and finds the aura whatever cast it; without
one the caster filter is unchanged, so every existing scenario is generated byte-identical (`generate --class 19`,
`--stack`).

## Consequences

`MinionAuraCountTests` (test_behaviours.py) checks both forms; a minion read that kept the caster filter is the mutant
that the Bonefreeze area entry would see as 0 frozen dummies.
