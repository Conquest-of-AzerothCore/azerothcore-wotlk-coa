# 0423. A held caster health and a selected primary

- Status: accepted
- Date: 2026-11-13

## Context

- Flesh Symbiosis 301207: "and causes you to periodically regenerate $805017s3% maximum health every $t2 sec." The
  handler adds health with `ModifyHealth` (AscensionNecromancerAuras.cpp:197-201), which logs no heal event, so the
  claim is read on the caster's health; `metric_delta` set the health of a creature target only.
- Command: Bonefreeze 504489 has no unit target; `Order()` falls back to the caster's victim or selection
  (AscensionNecromancerSummons.cpp:453-460). `fixed_count` cast it at the primary dummy without selecting it, and no
  dummy was frozen (pair prove-7, B3 side b).

## Decision

- `metric_delta` takes `caster_health_pct` (between 0 and 100, not with attack phases): the existing health fixture
  (`set_health` on the caster with the 10000 maximum) right before each trigger cast.
- `fixed_count` takes `select_primary`: a `select` of the primary dummy right before each cast.
- Without the fields every scenario is generated byte-identical (`generate --class 19`, `--stack`).

## Consequences

`CasterHealthAndSelectedPrimaryTests` (test_behaviours.py) checks both steps, the refused percents and an unselected
count's unchanged steps.
