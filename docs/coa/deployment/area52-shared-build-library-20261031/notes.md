## Area 52 Patch Notes - Shared Build Library

- **Save Build** saves to this server’s build library without uploading to GitHub.
- **Publish Build** shares a saved copy with the public Area 52 Build Architect Library after you confirm your public author alias.
- **Update Library** brings new and updated public builds into the existing in-game build list. Personal copies, active builds and Featured archetype assignments stay unchanged.
- Browse individual builds on GitHub and copy their build codes into **Import Build Code**.
- Shared builds are checked for level-by-level progression, prerequisites, point budgets and enchant limits before publication or import.
- Fixed the missing Featured build archetype dropdown and removed the 256-build list cutoff.
