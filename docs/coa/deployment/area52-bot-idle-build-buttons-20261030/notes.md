# Bot idle management and Build Architect buttons

- Bots leave the realm five minutes after the last human player leaves. Returning before the timer expires cancels the logout.
- Bots stay offline on an empty realm at startup. Their characters, equipment, archetypes and Vanity are retained.
- Fixed incomplete backgrounds on Copy Build, Copy Build Code and Import Build Code in Build Architect.

No ability, talent, Mystic Enchant or Certified status changes are included.
