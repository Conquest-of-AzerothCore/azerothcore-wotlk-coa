# Featured Build Vanity Editor and Catalog Updates

- GMs can save Featured Build armor, weapons, mounts, combat pets and incarnation rewards in the Build Editor.
- Saved vanity changes are queued for the launcher. Players receive the updated catalog when they next open the launcher and start the game.
- Character Creation equipment, pets and existing incarnation scenes follow the selected rewards. Mounts remain rewards rather than mounted preview scenes.
- Wardrobe sets and bundle contents now reflect assigned armor and weapons, including empty slots.
- Supported combat-pet selections grant the selected pet. Demon appearance selections change the matching summon’s appearance.
- Temporary Draft pets and appearances preserve independently owned rewards and become permanent through the existing Draft completion rules.
- Shirt, Tabard, neck, rings and trinkets remain excluded.
