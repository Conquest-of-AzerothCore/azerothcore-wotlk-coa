# Area 52 Patch Notes - Featured Build Enchant Slots

- Legendary Mystic Enchants now stay in the center slot when loading a Featured build.
- Epic enchants use Epic-capable slots; Rare and Uncommon enchants can fill the remaining slots.
- Existing misplaced enchants are rearranged when the affected setup loads, preserving the same enchants and stack counts.
- Already-valid layouts and your enchant collection remain unchanged.
